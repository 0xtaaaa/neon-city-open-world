Neon City is a top-down open-world crime game in the spirit of GTA 1/2, built as plain static files that run offline in a desktop browser. You are Vex's new driver in Neon City: steal cars, dodge the Neon City PD, and run four story jobs — a first getaway, a timed delivery, a cash-drop run, and losing the heat.

The city has roads, buildings and parks, traffic cars and pedestrians with their own AI, a wanted level (1–5 stars) that rises on crimes and decays when you hide, police cars that chase, ram and shoot, combat on foot (punch and pistol), pickups, a HUD with health, cash, ammo, wanted stars and a live minimap, a start screen, pause, and a save that continues from the title screen. Sound is synthesised live with WebAudio — engine hum, sirens, shots — with no audio files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. WASD/arrows to move and drive, E to enter/exit a car, F to punch, mouse + click to aim and shoot, Shift to run, P to pause, M to mute, C to continue a saved game on the title screen.
